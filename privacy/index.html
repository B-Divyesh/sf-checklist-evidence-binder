Privacy · 5 September 2026

Control your local evidence data

Proofbook stores procedures, records, names, notes, and evidence files in this browser’s IndexedDB. The binder is encrypted with AES-GCM using a key derived from your passphrase.

Network use

Normal binder use sends no record data to a server. Proofbook has no analytics, advertising, remote fonts, or third-party scripts.

Your controls

You can download a JSON backup or evidence report. You can remove each retained file, set automatic file retention, or erase the full binder.

The passphrase is not stored or sent. Keep a protected backup because a lost passphrase cannot be recovered.

Privacy requests

All binder data is controlled in your browser. Use Erase this binder in Binder setup to delete it.

Questions about this notice can be sent to privacy@sociobot.in.
